# تحكم باليد — فأرة ولوحة مفاتيح بالإيماءات

تطبيق بايثون يعمل على حاسوبك: يتتبّع يدك عبر الكاميرا (باستخدام MediaPipe Hands)
ويحوّل حركة سبابتك إلى تحريك فعلي لمؤشر الفأرة **على الشاشة الثانية**، مع دعم
النقر، النقر المزدوج، ولوحة مفاتيح افتراضية على الشاشة للكتابة — بنفس منطق
إيماءات صفحة "Finger Board" (المرفقة كمرجع) لكن موجّهة للتحكم بكامل نظام
التشغيل بدلًا من الرسم فقط.

## الإيماءات

| الإيماءة | التأثير |
|---|---|
| السبابة وحدها ممدودة | تحريك مؤشر الفأرة |
| السبابة + الوسطى معًا ممدودتان | تجميد المؤشر (لإعادة وضع يدك دون تحريكه، تمامًا كرفع فأرة حقيقية) |
| قرصة سريعة (الإبهام يلامس السبابة) | نقرة |
| قرصتان متتاليتان خلال أقل من نصف ثانية | نقرة مزدوجة |
| فرد الكف بكل الأصابع لمدة ثانية تقريبًا | إظهار/إخفاء لوحة المفاتيح الافتراضية |
| الضغط (بالقرصة) على مفتاح في اللوحة الافتراضية | كتابة ذلك الحرف في أي برنامج مركّز على الشاشة الثانية |

## التثبيت

يتطلب بايثون 3.9 - 3.11 (بسبب توافق حزمة `mediapipe`).

```bash
cd hand_mouse_keyboard
python3 -m venv .venv
source .venv/bin/activate   # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

على لينكس تحتاج أيضًا لتثبيت `xdotool` حتى تعمل خاصية "إعادة التركيز" عند
الكتابة عبر اللوحة الافتراضية:

```bash
sudo apt install xdotool   # دبيان/أوبنتو
```

## التشغيل

```bash
python3 app.py
```

ستظهر نافذة تحكم صغيرة فيها معاينة الكاميرا وزر "بدء". اضغط بدء، وسيبدأ
البرنامج بتتبع يدك وتحريك مؤشر الفأرة الحقيقي على الشاشة الثانية المكتشفة.

## الإعدادات

عدّل الملف `config.py` عند الحاجة:

- `CAMERA_INDEX`: رقم الكاميرا إن كان لديك أكثر من كاميرا (0 هي الافتراضية).
- `TARGET_MONITOR_INDEX`: اتركه `None` ليختار البرنامج الشاشة الثانية تلقائيًا،
  أو ضع رقم شاشة محدد (0 = الأولى، 1 = الثانية...) حسب ترتيب اكتشاف نظام التشغيل.
- `PINCH_RATIO`: حساسية القرصة (قيمة أصغر = يجب تقريب الإبهام والسبابة أكثر).
- `SMOOTHING_ALPHA`: نعومة حركة المؤشر (قيمة أكبر = استجابة أسرع لكن رجّة أكثر).

## بنية المشروع

- `app.py` — نافذة التحكم الرئيسية وحلقة معالجة الكاميرا.
- `hand_tracker.py` — تغليف MediaPipe Hands واكتشاف الإيماءات (امتداد الأصابع، القرصة).
- `smoothing.py` — تنعيم بسيط (متوسط أُسي متحرك) لتقليل رجّة تتبع الإصبع.
- `screen_utils.py` — اكتشاف الشاشات المتصلة واختيار الشاشة الهدف.
- `virtual_keyboard.py` — نافذة لوحة المفاتيح الافتراضية على الشاشة الهدف.
- `focus_helper.py` — أدوات لإعادة تركيز النافذة المستهدفة قبل إرسال كل حرف،
  حتى لا تسرق لوحة المفاتيح الافتراضية تركيز الكتابة من التطبيق الذي تكتب فيه.

## ملاحظات ومحدودات معروفة

- تم اختبار الشيفرة بالفحص النحوي فقط (`py_compile`) داخل بيئة التطوير هذه، لأنها
  بيئة سحابية بلا كاميرا ولا شاشة فعلية. جرّب التطبيق على جهازك وأخبرني إن
  واجهت أي عائق (رقم كاميرا مختلف، شاشة لا تُكتشف، إلخ).
- إعادة تركيز النافذة عند الكتابة تعتمد على `xdotool` في لينكس وعلى واجهات
  ويندوز الأساسية (`ctypes`) في ويندوز؛ macOS غير مدعوم حاليًا لهذه الميزة تحديدًا
  (باقي الميزات — التحريك والنقر — تعمل على أي نظام يدعم `pyautogui`).
- إن كان لديك أكثر من شاشتين، اضبط `TARGET_MONITOR_INDEX` يدويًا لاختيار
  الشاشة الصحيحة.
